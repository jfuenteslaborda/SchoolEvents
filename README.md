# SchoolEvents

**Autor:** José Fuentes Laborda

SchoolEvents es una aplicación web y móvil desarrollada con **Angular**, **Ionic** y **Spring Boot**. Su propósito es ofrecer un espacio donde los usuarios pueden registrarse, participar en eventos, interactuar en foros y comentarios, y consumir contenido multimedia relacionado con los eventos escolares.

---

## 📌 Funcionalidades principales

- **Registro y autenticación de usuarios:** Permite a los usuarios crear cuentas y autenticarse para acceder a todas las funcionalidades.
- **Participación en eventos:** Los usuarios pueden ver, inscribirse y participar en eventos escolares.
- **Foro y comentarios:** Espacio para que los usuarios puedan interactuar, preguntar dudas o comentar sobre los eventos.
- **Contenido multimedia:** Subida y visualización de imágenes, videos y otros recursos relacionados con los eventos.
- **Notificaciones:** Los usuarios pueden recibir avisos sobre nuevos eventos, comentarios o actividades en las que participan.

---

## 🛠 Tecnologías utilizadas

- **Frontend:** Angular, Ionic  
- **Backend:** Spring Boot  
- **Base de datos:** Postgres   

---

## 🚀 Instalación y ejecución

1. **Clonar el repositorio:**
```bash
git clone https://github.com/tu-usuario/SchoolEvents.git
cd SchoolEvents
```
2. **Backend (Spring Boot):**
```bash
cd schoolevents_api
./mvnw spring-boot:run
```
3. **Frontend (Angular + Ionic):**
```bash
cd schoolevents_ui
npm install
ionic serve
```
